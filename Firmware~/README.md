# The device's side: SFX FORGE 1.3.1 for VIBE FM

`sfx-forge.zip` is the built instrument (a "Vibe"). Drop the zip onto the window of the VIBE FM plugin; or unzip it
and drop `sfx-forge.wasm` onto the VIBE FM Playground, <https://play.thefirmwarehub.com/>, in Chrome or Edge.

How to play it: [the device's manual](../Documentation~/MANUAL.md). How to join it to Unity:
[section 6 of the Unity manual](../Documentation~/UNITY.md#6-from-the-device-to-the-game). It was run in the VIBE FM SDK's
tools and emulator only, not on hardware; the link was tested against the SDK's local emulator, not against the
Playground site or the plugin. Its source is not in this package.
